# 입력 흐름

시선으로 문장과 후보 단어를 대략 잡고, 제스처로 정확히 맞춘 뒤 메뉴를 고른다.

## 흐름
| 단계 | 사용자 동작 | 이벤트 | 상태 |
|---|---|---|---|
| 읽기 | 글을 읽는다 | `GAZE_PARAGRAPH` | `idle` |
| 문장 지정 | 시선 1초 멈춤(설정으로 켜고 끔) 또는 엄지 들기 | `TARGET_LOCKED` | `adjusting` / `word` |
| 단어 조정 | 엄지를 기울여 앞뒤 단어로 이동 | `TARGET_MOVED` | `adjusting` / `word` |
| 문장 바꾸기 | 손가락 모두 펴기 → 엄지 기울여 앞뒤 문장으로 이동 → 엄지+검지 | `TARGET_BACK`, `TARGET_MOVED`, `TARGET_CONFIRMED` | `adjusting` / `sentence` |
| 단어 확정 | 엄지+검지 들기 | `TARGET_CONFIRMED` | `menu` |
| 문장 해설 | 문장 조정 중 터치 단추 `해설` | `SENTENCE_EXPLAIN` | `result` (`scope: sentence`) |
| 메뉴 선택 | 손가락 1=단어 뜻 해석, 2=문장 해설, 3=LLM 검색 | `MENU_SELECTED` | `result` |
| 닫기 | 손을 펴고 양쪽으로 45도 이상 흔들기 | `CLOSE` | `idle` |
| 그만두기 | 주먹 (어느 단계에서나) | `CANCEL` | `idle` |
| 쪽 넘기기 | 읽는 중 화면 왼쪽·오른쪽 끝(폭의 15%)을 보며 손바닥 유지 | 앱이 쪽 이동 | `idle` |

시선 없이 시연할 때는 단어 클릭으로 지정하고 ←→(이동), Enter(확정), Backspace(문장 바꾸기), Esc(취소)를 쓴다. 드래그로 고른 글은 바로 메뉴로 간다.

## 제스처 기준
- 앞뒤 이동: 엄지가 세운 자세에서 오른쪽으로 35도 이상이면 뒤(다음), 왼쪽으로 35도 이상이면 앞(이전). 기울일 때마다 한 칸 움직이고, 15도 안으로 돌아와야 다시 움직인다.
- 단어 이동은 문장 경계를 넘어 이어지고, 문서(쪽) 양 끝에서 멈춘다.
- 메뉴의 2는 검지+중지다. 확정 제스처(엄지+검지)와 구분하기 위해 손가락 개수만 보지 않는다.
- 쪽 넘기기는 손을 내렸다 펴야 다시 동작하고, 흔들어 닫은 직후의 손으로는 넘어가지 않는다. 화면 끝에서는 시선 멈춤 지정을 하지 않는다.
- 뷰어에 들어오면 시선 보정 안내를 바로 띄우고 손 인식도 켠다. '나중에'를 누르면 시선 없이 읽을 수 있고, 다시 들어올 때까지 묻지 않는다.
- 보정 안내와 결과 화면에서 OK 표시(엄지·검지 끝을 붙이고 나머지 세 손가락을 편다)를 0.7초 유지하면 시작 또는 완료 버튼과 같다. 보정 점에서는 손을 펼 때마다 클릭 한 번으로 치고, 다음 클릭은 손을 0.2초 이상 접거나 내려야 받는다. 보정 중에는 읽기 제스처가 동작하지 않는다.
- 터치 기기에서는 단어를 탭해 지정하고, 조정 중에는 화면의 단추(이전, 다음, 문장 바꾸기, 확정, 취소)로 제스처와 같은 이벤트를 보낸다.
- 패드를 돌리면 카메라와 화면의 위치 관계가 바뀌므로 보정 안내를 다시 띄운다. 보정 중이었다면 처음으로 돌아간다.
- 시선 멈춤 지정은 왼쪽 패널에서 끌 수 있다. 읽기로 돌아온 뒤 2초간은 다시 지정하지 않고, 조정 중 10초간 입력이 없으면 읽기로 돌아간다.
- 각도와 시간 값은 시작값이다(`modules/hand/gestures.ts`). 실제 웹캠에서 조정한다.

## 구현 규칙
- 검지로 화면의 단어를 가리키는 방식은 쓰지 않는다. 단어는 시선 후보와 제스처 조정으로만 고른다.
- 후보 단어 목록과 위치는 `state/machine.ts`가 관리한다. 웹캠 없이 테스트한다.
- 메뉴 화면으로 넘어갈 때 손 모양이 바뀌어야 다음 제스처를 인식한다. 확정 제스처가 메뉴 선택으로 이어지지 않게 한다.
- 시선을 쓸 수 없으면 마우스로 대신 지정할 수 있어야 한다.
- 단어를 확정하면 직전 0.5초 시선과 단어 중심의 차이를 재서 좌표를 25%만 옮긴다(`modules/gaze/wordCorrection.ts`). 220px 넘게 떨어졌거나 시선이 움직이던 중이면 버린다. 모델은 다시 학습하지 않고, 보정량은 200px까지이며 시선을 끄거나 다시 보정하면 지워진다.
